# Ink ✍️

Ink is a simple, beautiful story writing app built to help writers focus on creating, not formatting.

It provides a clean editor, smooth writing experience, and tools to organize and edit stories without distractions.

## ✨ Features

- 📝 Clean, distraction-free writing interface  
- 📚 Organize stories and chapters  
- 🎨 Minimal UI focused on creativity  
- ⚡ Fast and lightweight

## 🧠 Why I built it

I wanted a writing app that feels calm and simple, without clutter or unnecessary features.  
Ink is built for writers who just want to open the app and start writing.
