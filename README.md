# Ink ✍️

Ink is a simple, beautiful story writing app built to help writers focus on creating, not formatting.

It provides a clean editor, smooth writing experience, and tools to organize and edit stories without distractions.

## ✨ Features

- 📝 Clean, distraction-free writing interface  
- 🖥 Fullscreen writing mode for deep focus  
- 👤 Guest mode (start writing without signing up)  
- 📚 Organize stories and sheets/chapters  
- 🎨 Minimal UI focused on creativity  
- ⚡ Fast and lightweight  
- 💾 Save and manage your stories  

## 🧠 Why I built it

I wanted a writing app that feels calm and simple, without clutter or unnecessary features.

Most writing apps either feel too complex or force you to create an account before you can even start writing.  
Ink lets you jump straight into writing, and only sign up if you want to save your work online.

- Next.js  
- React  
- TypeScript  
- BlockNote (editor)  
- Firebase (auth + storage)  
- Tailwind CSS + shadcn/ui
